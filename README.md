# PrahariAI

**Fraud moves in seconds. Prahari moves before it does.**

PrahariAI is a digital public safety intelligence platform built to fight India's fastest-growing
fraud threats: digital arrest scams, counterfeit currency, and organised fraud rings operating
across phone, UPI, and shell-account networks.

Every year, thousands of Indians lose their life savings to fraudsters impersonating police
officers over video call, and counterfeit notes continue to slip past manual detection in routine
transactions. The tools to stop this exist — the problem has always been that no single system
connects the signals in time. PrahariAI is that connective layer.

## What it does

**Digital Arrest Scam Detector** — Analyzes a call transcript in real time and flags the exact
markers of a digital arrest scam: false claims of law-enforcement authority, forced isolation from
family, urgency to transfer funds, and OTP requests — before a single rupee moves.

**Counterfeit Note Scanner** — Point a camera at a currency note. The engine checks it against
known RBI security features: security thread, latent image, microprinting, and watermark clarity.

**Fraud Network Graph** — Clusters phone numbers, UPI IDs, devices, and mule accounts pulled from
linked victim reports into a single traceable fraud ring, instead of leaving each complaint
isolated.

**Geospatial Hotspot Map** — City-level severity mapping across fraud categories, so patrol and
awareness resources go where the next wave is forming.

**Citizen Fraud Shield** — Anyone can describe a suspicious call or message in plain language and
get an instant, jargon-free verdict on whether it's safe — plus what to do next.

## Why it's different

Existing fraud tools react after a complaint is filed. PrahariAI is built to act at the point of
contact — while the call is still happening, while the note is still in someone's hand — because
by the time a complaint is filed, the money is usually already gone.

## Built with

Flask, SQLite, Groq (Llama 3.3 for language reasoning, Llama 4 Scout for vision), vis-network,
Leaflet, Three.js, and GSAP.
